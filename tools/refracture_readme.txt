Refracture XR
=============

An independent fork of Refract. Based on Refract: https://github.com/MIXIDtheSilly/Refract

This package is Refract's own release (the runtimes, the translator, the GPU and VR programs) with Refracture XR's
launcher on top. The launcher is the one that adds the "Unknown sources" page: games that are not from the Meta
store (your own builds, itch.io releases, ports), added as an APK or a folder, with no Meta sign-in.
See docs\unknown_sources.md. UPSTREAM.txt names the Refract release this was made from.

Start it the way Refract starts: unzip somewhere permanent and open Refract.exe (Windows), or unpack and run ./Refract
(Linux). Then open Settings > Setup and click each button until everything is green. Refract's own README.txt, kept
in this folder, explains the rest.

Your games, settings and Meta sign-in live in the same place as Refract's (%APPDATA%\Refract on Windows), so the two
can be switched between.
